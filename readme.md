# AI-Driven Faculty Performance Evaluation System

An AI-driven system designed to evaluate and analyze faculty performance using multiple academic and professional performance parameters.

The project aims to provide a structured, data-driven approach to faculty evaluation and help institutions identify performance trends, strengths, and areas for improvement.

## 🚀 Project Overview

Traditional faculty evaluation often depends on manual reviews and subjective feedback. This project uses data analysis and machine learning concepts to make the evaluation process more systematic and data-driven.

The system can analyze faculty-related performance data and generate meaningful insights based on defined evaluation parameters.

## ✨ Key Features

- Faculty performance data analysis
- Performance scoring and evaluation
- Data preprocessing and cleaning
- Feature-based performance analysis
- AI/ML-based evaluation
- Performance insights and comparison
- Visualization of faculty performance trends
- Structured evaluation reports

## ⚙️ Setup & Run

### Backend

```bash
cd backend

# Create virtual environment
python -m venv venv

# Activate environment
# Windows
.\venv\Scripts\activate

# Linux / Mac
source venv/bin/activate

# Install dependencies
pip install -r requirements.txt

# Run backend server
uvicorn app:app --reload


## Frontend

cd frontend

# Install dependencies
npm install

# Start React development server
npm run dev
